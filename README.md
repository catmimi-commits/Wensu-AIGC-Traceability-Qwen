# Wensu-AIGC-Traceability-Qwen

本项目面向中文新闻概括场景的 AIGC 双轨制溯源，构建了完整的“闻溯”检测系统。相关实验融合正交 KGW 主动水印与轻量化浅层文风指纹。开源提供相关源码及实验用数据集，以辅助实现大模型代际版本（Qwen1.5/2/2.5）精准归因与全网巡查。

---

## 项目简介

- **场景**：中文新闻短文本（<300字）概括性改写
- **目标**：从“是否AI生成”到“具体哪一代Qwen模型生成”
- **方法**：主动水印（KGW+正交密钥）+ 被动指纹（浅层统计+TF-IDF）
- **本仓库开放**：核心实验代码、检测模型、采样数据集、系统源码

---

## 重要说明：模型文件与系统源码的关系

为便于模型文件的统一管理与有需要的用户单独进行模型复用，本项目已将**系统源码中使用的 Qwen 相关分词器、检测器模型及相关配置**优先提炼出来，集中存放于本仓库的 **`watermark_models/`** 目录中。

因此，**`系统源码/`** 目录下为本地化部署系统的其他文件（不含已提炼的模型与分词器）。若您需要完整部署本系统，请：

1. 先阅读 `系统源码/README.md`；
2. 按照该 README 的说明，将 `watermark_models/` 中的相关文件移动/复制到 `系统源码/` 的指定位置；
3. 再按部署文档完成本地化部署。

这样可避免模型文件在仓库中重复存放，也方便您按需取用。

## 仓库结构

```
Wensu-AIGC-Traceability-Qwen/
├── watermark_models/          # 从系统源码中提炼的检测模型、分词器与配置
├── 四领域短文本数据集/         # 体育、科技、教育、时政四领域采样数据
├── 实验代码/                   # 消融、跨领域迁移、水印归因等实验脚本
├── 系统源码/                   # 本地化部署系统其他文件（详见其内部 README）
├── LICENSE                    # Apache-2.0
└── README.md                  # 本文件
```


### 各目录说明

- **`watermark_models/`**：Qwen1.5/2/2.5 水印检测所需分词器与配置（完整模型可自行搜索 Hugging Face 下载）；本项目自研的检测模型（`.pkl`）也在此目录，通过 Git LFS 存储。
- **`四领域短文本数据集/`**：体育、科技、教育、时政四领域采样数据（原新闻文本取材自 THUCNews 新闻数据集）。
- **`实验代码/`**：消融、跨领域迁移、水印归因等实验脚本（相关环境依赖见目录内 `requirements.txt`）。
- **`系统源码/`**：本地化部署系统的其他文件；**模型与分词器已提炼至 `watermark_models/`，使用前请参考其内部 README 进行文件移动。**
- **`LICENSE`**：Apache-2.0。
