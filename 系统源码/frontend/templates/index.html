基于清华 THUCNews 语料，覆盖体育、科技、教育、时政四个领域，每领域含人类文本及Qwen1.5、Qwen2、Qwen2.5生成文本，形成"4领域×4来源"平衡结构。数据构建模拟真实"概括性改写"场景，将500-1000字原始新闻压缩至300字以内，聚焦文风差异而非内容复述；并从中抽取源文本用于主动KGW水印的嵌入与检测实验。评价指标含准确率、精确率、召回率与Macro F1。

主动水印实验

闭域无攻击基准 · KGW 水印
实验一

基准水印检出性能

闭域无攻击环境下三模型误报率均为 0.00%，检出率 83%~91%；模型参数量增大使检出率微幅下降，但带水印样本 Z-score 仍远超阈值（Qwen2.5-1.5B 达 8.57）。

为三种模型分别分配正交伪随机密钥（Key 62 / 52 / 42），在绿名单比例 γ=0.25、判定阈值 τ=3.5 下，每模型各生成 200 组无水印与 200 组带水印样本。随着参数量由 0.5B 增至 1.5B，其 logits 分布更陡峭、置信度更高，固定强度偏置更难改变采样结果，导致检出率符合理论预期地微幅下降。

实验二

跨密钥源头归因与伪随机正交性验证

将三模型带水印文本混合后交叉解码，源头归因准确率达 100.0%，跨密钥碰撞率 0.0%，验证了密钥正交隔离性。

采用最大响应准则，用候选解码密钥集交叉评估文本响应。正确密钥可恢复一致的绿名单使 Z-score 显著拉升；错误密钥解码时绿名单与实际 token 分布完全解耦，响应坍缩至无水印水平。混淆矩阵对角线呈深蓝极化，表明只要为不同模型分配独立正交密钥，闭域环境下主动水印溯源具备绝对可行性与极高精准度。

被动指纹实验

语义分布 · 跨域迁移 · 代际演进
实验三

语义几何结构与天然区分度

无需任何训练，Qwen各版本在语义空间已呈现天然的"带状分离"与"簇状聚集"，证明"版本指纹"是模型内生的。

在不经过任何监督标签或分类器训练的无监督状态下，仅提取句级语义向量进行 t-SNE 降维，即可观察到 Qwen1.5、Qwen2、Qwen2.5 在二维空间中呈现明显几何结构，且在各新闻领域有一定偏差。这证实：大模型版本迭代不仅改变了参数权重，也重塑了其输出文本在语言表征空间中的统计与结构偏好——为利用文风指纹进行细粒度版本溯源提供了存在性前提。

实验四

跨领域迁移与联合训练

指纹具有强领域依赖性，科技领域形成"孤岛"（迁移准确率＜40%）；而全领域联合训练可将科技识别准确率从 38.3% 填平至 83.3%。

留一域交叉验证显示：单一领域训练迁移至其他领域时准确率普遍下降，科技领域呈显著"孤岛效应"——其高密度专业术语与强事实约束形成高度特化的"专业语体"，迁移准确率均低于 38%（接近随机）。而教育与时政间存在良好双向迁移（平均 58%~59%）。递进式联合训练进一步表明：文风指纹由"通用写作惯性（共性指纹）"与"特定语域偏好（特性指纹）"共同构成，多领域联合训练能成功"填平"科技孤岛。

实验七

两种检测方法的鲁棒性衰减对比

两种范式在改写攻击下衰减模式不同：主动水印呈"临界断崖"（20%替换即断崖式下跌），被动指纹呈"阶跃坍塌"（轻度润色即从89.00%骤降至49.00%）。

对带水印文本施加 0%~30% 随机替换攻击，对被动分类器施加 L1 轻度润色 / L2 句式重构 / L3 深度改写。主动水印在 10% 替换下仍保持 57.0%~70.0% 检出率，但 20% 时 TPR 断崖式跌至 13.0%~34.7%，30% 趋近失效（0.0%~11.0%）——因随机替换打断了作为 PRNG 种子的前置 token 链条。被动指纹基线 89.00%，仅需 L1 轻度润色即剧降至 49.00%，L2/L3 进一步衰减至 40.67%/43.67%，逼近三分类随机基准（33.33%）——因改写直接抹去或重塑了 TF-IDF 词汇偏好。

实验八

两种方法的机理对比与共同脆弱性

两种范式均未建立深层语义不变性，在同义替换、语序调整下呈现共同脆弱性；工程实践须构建"主动预警 + 被动巡查"的双层级联防御。
对比维度 主动水印（KGW） 被动指纹（统计+TF-IDF）
检测原理PRNG 种子链 · 绿名单概率偏置词频 / 表层统计文风指纹

无攻击精度TPR 83%~91%，归因 100%四分类平均 89.0%
响应速度毫秒级轻量快速
改写鲁棒性临界断崖（20% 替换即失效）阶跃坍塌（轻度润色即降至 49%）
共同脆弱性均缺乏语义不变性表达，改写扰动下同步失效

主动水印依赖局部 token 序列连续性维持 PRNG 种子链，被动指纹依赖高频词与表层句式，二者均未建立深层语义不变性。引入 RoBERTa 等深层语义特征在短文本改写场景下又易引发过拟合与准确率下降。因此单防范式难以应对复杂对抗环境，须融合主动水印的"强源头归因"与被动指纹的"无侵入巡查"，构建双层级联防御架构以克服单一方法的鲁棒性边界。
